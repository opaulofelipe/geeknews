# Geek News

Projeto estático em **HTML, CSS e JavaScript puro** para publicação no GitHub Pages.

## Conceito

Versão repensada com foco em:

- aparência editorial premium
- tipografia mais sofisticada
- layout mais elegante e menos “portal genérico”
- categorias sem contadores
- estrutura pronta para crescer além de 5 matérias
- busca, filtro por categoria, modal de leitura e menu responsivo

## Estrutura

- `index.html`
- `styles.css`
- `script.js`
- `assets/images/`

## Publicação no GitHub Pages

1. envie os arquivos para a raiz do repositório
2. vá em **Settings > Pages**
3. em **Build and deployment**, escolha **Deploy from a branch**
4. selecione a branch principal e a pasta `/root`
5. salve
